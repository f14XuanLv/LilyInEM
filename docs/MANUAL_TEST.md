# LilyInEM 手动测试清单（v0.3.0，2026-10-18 更新菜单 / 休息点部分）

> 启动：`tools\stop.ps1` → `tools\deploy.ps1` → `tools\start.ps1 -Role host`（Host 自动拉起无头 EL，自动继续存档 0）。
> 观测：EM 窗口按 `F10` 打开计数面板；或运行 `tools\eval.ps1 -Role host -Code "return LIE_HostStatus()"` / `-Role guest -Code "return LIE_GuestStatus()"`。
> 想看 EL 原始画面：先设环境变量 `LIE_SHOW_GUEST=1` 再启动。
> 日志：`<实例>\ue4ss\UE4SS.log`，筛选 `[MagnoliaHost]` / `[LiliesGuest]`。
> 每项写 ✅ / ❌ / ⚠️ + 现象（失败时最好附 F10 面板截图与两边 Status 输出）。

键位：移动 WASD/左摇杆/十字键 · 跳 Space/Z/A · 闪避 LShift/C/RT · 主攻 H/X/X键 · 副技1 J/Y键 · 副技2 K/B键 · 切换精灵组 L/RB · 祈祷 Q/LB · 交互/钩爪 E/LT
热键：F5 莉莉 Esc 菜单（EL 原生 WBP_Pause；EL 自己的 Esc 入口已全部拦截） · F6 快捷装配面板（莉莉休息菜单只在 EM 长椅出现） · F7 莉莉/莱拉克切换 · F8 显示莱拉克（调试） · F10 计数面板
